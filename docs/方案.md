1. 所有调用模型都使用旗舰模型api，使用agent程序调用，对视频、音频的处理使用自己的脚本；（成本最高，最快）
2. 自己训练小参数模型（4B）专门用于识别图片和文本结合的评论+视频中的诈骗风险，然后交给自己训练的9B参数模型识别所有数据加一起的情景是否含有诈骗风险，agent负责音频转文本后提取可能含有诈骗风险的视频帧区间（成本最低，调用本地模型速度不会很快，审查一条视频可能需要好几分钟）
3. 自己训练小参数模型（4B）专门用于识别图片和文本结合的评论+视频中的诈骗风险，agent调用旗舰模型审查可能含有诈骗风险的视频帧区间，交给小参数模型（4B）识别是否含有风险，然后将所有数据拼接起来交给旗舰大模型来审查（成本中等）
4. 所有方案都可以做的：agent调用反诈知识库，可以由模型自己审查过程中总结出诈骗套路存入知识库，新的数据审查时可以检索，如果符合就能直接确定含有诈骗风险，无需调用其他的工具或者模型。
